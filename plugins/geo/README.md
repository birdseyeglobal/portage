# GEO Plugin

Generative engine optimization workflows for teams that track how brands appear in AI-search and LLM answer surfaces.

The skills are intentionally data-first. They work from brand context, prompt execution exports, URL-level citation exports, keyword research, competitor domains, and live page review. They do not assume a specific agency, brand, report design, or private account.

## Skills

### Prompt Generation

Creates natural-language prompt sets for LLM visibility tracking. Prompts are grouped by topic and funnel stage, and written in the vocabulary buyers actually use rather than the brand's internal language.

### Content Briefs

Turns prompt execution data, citation URLs, competitor pages, AI responses, and keyword evidence into writer-ready content briefs. Use it when generic templates would produce similar briefs across different markets.

### SEO Competitor Research

Produces a search and competitor strategy report from a target domain, competitor domains, keyword data, and SERP evidence. It can use paid SEO tools when available, but the report must identify the data source and date.

### Sitemap Strategy

Audits an existing site against the page types competitors and third-party sources win citations with, then separates recommendations into pages to improve and pages to create.

### Reddit Citation Analysis

Analyzes Reddit citations in LLM tracking exports. It profiles cited subreddits, branded versus unbranded thread patterns, competitor tactics, sentiment signals, and a responsible engagement plan.

### Visibility Progress Report

Builds an executive progress narrative from time-series prompt execution data: visibility trend, topic movement, platform gaps, cited owned URLs, and next focus areas.
