# Input Format

The skill can adapt to different tracking exports. Map available columns into these concepts.

## Prompt Executions

Useful columns:

- `Prompt`: the tracked query.
- `Topic`: topic, product line, or cluster.
- `Funnel Stage`: TOFU, MOFU, BOFU, or equivalent.
- `Platform`: model or AI-search surface.
- `Workspace Brand Mentioned`: whether the tracked brand appeared.
- `Competitor Mentioned`: whether competitors appeared.
- `Competitor Mentions`: named competitors, if present.
- `Citations (Links)`: cited URLs.
- `Citation Domains`: cited domains.
- `AI Response`: response text.
- `Execution Date`: useful for trend-aware briefs.

## Citation Exports

Useful columns:

- `url`
- `title`
- `root_domain`
- `full_domain`
- `type`: OWNED, EARNED, COMPETITOR, SOCIAL, or similar.
- `frequency`
- `unique_executions`
- `prompt`
- `topic`

## Keyword Research

Useful columns:

- `keyword`
- `volume`
- `keyword_difficulty`
- `position`
- `traffic`
- `url`
- `serp_features`
