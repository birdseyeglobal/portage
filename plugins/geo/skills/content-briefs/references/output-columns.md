# Output Columns

Recommended CSV columns:

- `Priority`
- `Topic`
- `Funnel Stage`
- `Target Prompt`
- `Primary Keyword`
- `Target Word Count`
- `Audience`
- `Citation Gap Evidence`
- `Top Cited Sources`
- `Competitor Patterns`
- `AI Response Pattern`
- `Brand Angle`
- `Article Outline`
- `Required Entities`
- `Suggested Sources`
- `Internal Links`
- `Schema Recommendation`
- `Writer Checklist`

The `Article Outline` cell should be self-contained. Include section names, what each section should cover, examples or entities to mention, and the reason each section matters.
